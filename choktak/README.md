# 촉탁신청서 제작 RPA

근저당권이전등기 **촉탁신청서**를 자동으로 생성하는 RPA입니다.
촉탁명세서(엑셀) 한 행마다 촉탁신청서 PDF 한 장을 만들어 냅니다.

## 입력

| 구분 | 파일 | 설명 |
|------|------|------|
| 촉탁명세서 | `samples/촉탁명세서_예시.xlsx` | 한 행 = 촉탁신청서 1건. 아래 A~I 컬럼 |
| 은행목록 | `choktak/data/은행목록.xlsx` | 취급기관명 → 법인번호·주소 (등기의무자 조회용) |
| 등기부등본 | `samples/등기부등본/*.pdf` | 부동산의 표시 파싱용. 파일명으로 명세서 행과 매칭 |

**촉탁명세서 컬럼(A~I)**

```
번호 | 대출계좌번호(A) | 채무자명(B) | 취급기관명(C) | 관할등기소(D)
    | 양수일자(E) | 등기일자(F) | 등기접수번호(G) | 등록세(H) | 지방세(I)
```

## 처리 로직 (개발 매뉴얼 기준)

1. **촉탁명세서 매핑** — A~I 값을 촉탁신청서의 해당 위치에 삽입
   - `관리고유번호 : C(취급기관명)`, 상단 `B(채무자명) (A(대출계좌번호))`
   - 등기원인 `E 확정채권양도`, 이전할 근저당권 `F 제 G 호로서 등기한 근저당권`
   - 등록면허세 `H`, 교육세 `I`, **합계 = H + I**
   - `D(관할등기소) 귀중`
2. **은행목록 조회** — 취급기관명(C)으로 등기의무자의 법인번호·주소를 채움
3. **등기부등본 파싱**
   - 대지권 목적 토지 소재지번은 **취소선(말소선)이 없는 최후 행**을 사용
     (등기부에서 말소·변경된 행은 텍스트 위에 수평선이 그어져 있음 → 벡터선으로 검출)
   - 1동 건물표시 끝의 **제N동**을 전유부분 건물번호 앞에 접두
     (예: `제10층 제1005호` → `제310동 제10층 제1005호`)
4. **등기권리자**는 한국주택금융공사(고정), **신청일자는 오늘 날짜**
5. **PDF 생성** — 나눔고딕(본문 Regular/Bold), 맨 아래 `○○ 귀중`은 **나눔고딕 ExtraBold**

## 실행

```bash
pip install -r requirements.txt

# 기본 (samples/ 폴더 사용)
python -m choktak.main

# 경로 지정
python -m choktak.main \
    --myeongse 촉탁명세서.xlsx \
    --deungbon-dir 등기부폴더 \
    --output 출력폴더
```

생성된 PDF는 `output/` 폴더에 `{번호}_{채무자명}_촉탁신청서.pdf` 형식으로 저장됩니다.

## 구조

```
choktak/
  config.py           설정(경로·폰트·고정값: 등기권리자/수수료 등)
  myeongse.py         촉탁명세서(xlsx) 읽기
  bank_directory.py   은행목록 조회 (취급기관명 → 법인번호·주소)
  deungbon_parser.py  등기부등본 PDF 파싱 (취소선 검출 포함)
  pdf_builder.py      촉탁신청서 PDF 생성 (reportlab)
  main.py             전체 오케스트레이션
  data/은행목록.xlsx
fonts/                NanumGothic Regular/Bold/ExtraBold (SIL OFL)
samples/              예시 입력(촉탁명세서, 등기부등본)
```

## 등기의무자 주소 관련 메모

등기의무자(성명·주소)는 **촉탁명세서의 취급기관명(C) → 은행목록 조회** 결과를 사용합니다.
등기부등본 을구의 근저당권자 주소가 아니라 은행목록 값을 쓰는 것이 매뉴얼 규칙입니다.
